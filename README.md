# Continental Crop Yield Prediction and Cross-Country Transfer Limits Across Africa

## Overview
This repository contains a working, executable reproduction of the methodology described in
*A Generalizable Machine Learning Framework for Continental Crop Yield Prediction Across Africa*
(Shahzaib & Khan, submitted to *Precision Agriculture*, Springer, under editorial assessment).

The panel covers 52 African countries, 1990-2024, 1,770 country-year observations, built from
FAOSTAT (cereal yield, fertilizer inputs), FAOSTAT Environment/Temperature Change, and NASA POWER
(precipitation, growing degree days). Eight ML architectures are benchmarked under both a temporal
split and leave-one-country-out (LOCO) validation, testing whether models generalize across
countries or merely memorize country-specific yield baselines.

**A note on provenance, stated plainly:** the notebook in `notebooks/` is a clean-room
reproduction, written to match the manuscript's documented methodology. It is not the original
code used to produce the published paper, which was not preserved in a clean, standalone form.
The panel itself is built from files recovered from the author's own project folder (a base
FAOSTAT/fertilizer panel, FAOSTAT temperature change data, and precipitation/GDD extracts), merged
and filtered to the 52-country scope described in the manuscript. The notebook is fully executable
and its outputs in `results/` and `figures/` were generated by actually running it, not copied from
the paper.

## How the reproduction compares to the published manuscript

Running the same methodology on this reconstructed panel lands in the same range and supports the
same conclusions as the manuscript, but does not match to the decimal. Differences are expected:
this panel uses reconstructed precipitation and GDD data (not the authors' original NASA POWER
pull), a different random seed for the LOCO country-to-fold assignment, and no per-feature
hyperparameter tuning beyond what the manuscript specifies.

| Metric | Manuscript | This reproduction |
|---|---|---|
| Temporal R\u00b2 with yield lag (Linear, best) | 0.948 | 0.944 |
| LOCO R\u00b2 with yield lag (Linear, best) | 0.853 | 0.802 (mean fold) |
| LOCO R\u00b2 without yield lag (Linear) | 0.148 | 0.106 |
| LOCO R\u00b2 without yield lag (worst tree model) | \u22121.214 (LightGBM) | \u22120.389 (XGBoost) |
| Mean R\u00b2 drop ratio, tree vs. linear | 2.3x | 1.37x |
| Bias correlation (Random Forest) | r = 0.854 | r = 0.889 |
| Bias correlation (Linear) | r = 0.837 | r = 0.639 |
| GDD sensitivity: any model significant? | Yes (Gradient Boosting) | No, in this run |

**What holds up:** every tree-based model collapses to negative LOCO R\u00b2 once historical yield is
removed, while both linear models stay modestly positive \u2014 the manuscript's central finding.
Per-country prediction error is dominated by systematic offset rather than noise, and that offset
correlates with a country's distance from the training distribution, for both models tested.
SHAP attribution also shows the same qualitative pattern: historical yield dominates when present,
fertilizer inputs take over once it is removed.

**What doesn't match exactly:** the magnitude of the tree-vs-linear gap is smaller here (1.37x vs.
2.3x), and the GDD sensitivity test did not reach significance for any model in this run, whereas
the manuscript found a significant improvement for Gradient Boosting. With only 7 LOCO folds,
this test has limited statistical power, and reconstructed GDD values likely differ somewhat from
the authors' original NASA POWER extraction.

## Feature set
Six predictors, matching the manuscript: total nitrogen, phosphorus, and potassium fertilizer
input, total annual precipitation, annual temperature change, and one-year lagged cereal yield
(dropped for the "transferable" / no-historical-yield scenario). Growing degree days is added only
for the sensitivity test in Section 7 of the notebook.

## Models
Linear Regression, Lasso, Random Forest, Extra Trees, Gradient Boosting, XGBoost, LightGBM,
CatBoost. All tree-based models use 300 estimators; other hyperparameters follow library defaults.
Linear models are fit on standardized features.

## Validation
- **Temporal split:** train on years \u22642017, test on \u22652018.
- **Leave-one-country-out (LOCO):** 7-fold, countries grouped randomly into folds (seed 42);
  each fold's countries are held out from training entirely.

Statistical comparisons (with vs. without historical yield; with vs. without GDD) use paired
t-tests across the 7 LOCO folds, since fold composition is identical across each comparison.

## How to run
1. Clone the repository.
2. Install dependencies: `pip install pandas numpy scikit-learn scipy xgboost lightgbm catboost shap matplotlib jupyter`
3. From the repository root, open and run `notebooks/africa_crop_yield_pipeline.ipynb` top to bottom.
4. Outputs are written to `results/` and `figures/`, overwriting the versions already committed.
